# Monster classes

Every monster, turret and player belongs to a class, and the classes decide who fights whom, who fears or ignores
whom, and who fights on the players' side. When a monster sees another monster or a player, the game looks up both
classes in the tables below. The class keys of the monsters, of [`monstermaker`](../entities/monstermaker.md),
[`func_tank`](../entities/func_tank.md), [`trigger_sensor`](../entities/trigger_sensor.md) and
[`monster_target`](../entities/monster_target.md) use the same class names.

## What changes a monster's class

- [**Classification**](../entities/common-keys.md#monstercore) on a monster puts it in another class. "None" takes
  it out of every class, so nobody fights it and it fights nobody
- **Is player ally** set to "Yes" makes a monster without a **Classification** change sides: a Human passive or
  Player ally monster becomes Human military, a monster of class None stays None, and any other monster becomes a
  Player ally
- A [`monstermaker`](../entities/monstermaker.md) gives its **Children's classification** and **Reverse
  Relationship** to every monster it makes
- A [`monster_osprey`](../entities/monster_osprey.md) gives its own **Classification** and **Is player ally** to the
  Feds it drops
- **Prisoner to** on a monster names a class, and the monster and the monsters of that class ignore each other, so
  the tables don't apply to that pair
- **Ignored by** on a monster names a class whose monsters ignore the monster, while the monster still sees them

## Exceptions to the table

- A [`monster_human_grunt`](../entities/monster_human_grunt.md), a
  [`monster_grunt_hunter`](../entities/monster_grunt_hunter.md) and a [`dark_grunt`](../entities/dark_grunt.md)
  treat a [`monster_gargantua`](../entities/monster_gargantua.md) as their nemesis
- A [`monster_cyberminotor`](../entities/monster_cyberminotor.md) treats a `monster_human_grunt` as its nemesis, but
  it only hates a `monster_grunt_hunter`
- A [`monster_generic`](../entities/monster_generic.md) (Generic Script Monster) has no AI, so it never attacks,
  flees or follows. Its class only sets how other monsters treat it: by default it is a player ally, so monsters that
  fight players, such as the Apache, attack it. Its **Classification** key changes who attacks it, not what it does
- A Scientist, or a Cop the map makes a player ally, hates players from then on if players hit it too often, and its
  **Tolerance level** sets how many hits it takes. A Cop is an enemy of players by default, so this only matters for
  an allied Cop
- With **Pre-provoked** set to "Yes", a Scientist dislikes players from the start and doesn't fear them
- A [`monster_dark`](../entities/monster_dark.md), a [`monster_alien_slave`](../entities/monster_alien_slave.md), a
  [`monster_hunter`](../entities/monster_hunter.md), a [`monster_werewolf`](../entities/monster_werewolf.md) or a
  [`monster_werewolf_hunter`](../entities/monster_werewolf_hunter.md) with the flag **Wait until provoked** (64)
  ignores players until a player provokes it
- A Pitbull's class depends on what it chases (see the list above)
