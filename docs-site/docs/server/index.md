# Server setup

These pages are for you if you run an SBO server. SBO runs on the Half-Life Dedicated Server (HLDS) and on the
listen server you start from the game's menu in Steam Half-Life.

| Page | What it covers |
|---|---|
| [Server settings](settings.md) | Every game cvar (a console setting) with its default |
| [Server files](files.md) | `server.cfg`, `listenserver.cfg`, the MOTD, the map cycle, map briefings, `maps/map_compat.txt` and `spectators.txt` |
| [Server logs](logs.md) | The lines the game writes to the server log |
