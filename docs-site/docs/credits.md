# Credits

SBO 2.0.0 is built with code, entities and features from the projects below, and every page and key that comes from
one of them shows that project's "Ported from" icon, which links to the project.

| Project | What SBO uses from it |
|---|---|
| [Half-Life Featureful SDK](https://github.com/FreeSlave/halflife-featureful) | Locus keys and calc entities, [`env_state`](mapping/entities/env_state.md), [`calc_state`](mapping/entities/calc_state.md), [`trigger_inout`](mapping/entities/trigger_inout.md), [`env_model`](mapping/entities/env_model.md), [`trigger_jump`](mapping/entities/trigger_jump.md), [`trigger_safe_fall`](mapping/entities/trigger_safe_fall.md), [`trigger_sensor`](mapping/entities/trigger_sensor.md), [`trigger_random`](mapping/entities/trigger_random.md), [`trigger_timer`](mapping/entities/trigger_timer.md), [`game_messagebox`](mapping/entities/game_messagebox.md), the **Touch proxy name** key of [`func_vehicle`](mapping/entities/func_vehicle.md), object hints, many keys and flags on Half-Life entities, the material registry |
| [Spirit of Half-Life](https://github.com/LogicAndTrick/halflife-updated) (1.8 bug-fix branch), [Spirit of Half-Life 1.9](https://github.com/sohl-modders/Spirit-of-Half-Life-1.9), [SoHL 1.2](https://github.com/Admer456/halflife-vs2019-sohl12) | [`env_particle`](mapping/entities/env_particle.md) (Aurora) and its scripts, [`env_mirror`](mapping/entities/env_mirror.md), [`env_sky`](mapping/entities/env_sky.md), [`trigger_lightstyle`](mapping/entities/trigger_lightstyle.md), teleport landmarks, model scale, the first version of the locus system |
