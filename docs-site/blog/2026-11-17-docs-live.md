# The 2.0.0 docs are live

After a few weeks of writing, checking, updating and rereading, the 2.0.0 docs are finally available for everyone.
They're dense: I tried to cover everything, from installing and playing the game to what each entity does and how to
use it. These docs, and SBO 2.0.0 itself, are the result of years of work. I wrote about how it all came together in
the [SBO 1.38 Retrospective](https://retro.sbo.sbotnas.io/).

<!-- truncate -->

A copy of the docs also ships with the game, in `syndicate/manual/` (open `index.html`), and the in-game updater
brings it up to date with every release. It will usually match this site, but check back here from time to time to
confirm what you read.

With work on this scale, there are bound to be bugs, confusing sentences, or things that are just plain wrong, either
because I changed how something works after writing about it and missed the page, or because it never worked the way
I described. These should be rare, but if you're really stuck on something, the best place to ask is the
#syndicate-blackops channel on [Discord](https://discord.sbotnas.io).

Every release goes through a lot of checking before it reaches you. I run memory and crash checks on the game code, a
few hundred automated tests of the entities and game rules, and a test that plays every stock and custom map on the
new version and on 1.38 side by side, so maps keep working the way they always have. It isn't a perfect process and
things can still slip through, but I try hard to catch them before you do.

As a reminder, all of this work has been, and still is, done by me alone in my free time: running the servers,
writing AMX Mod X plugins and Metamod modules for the servers, diagnosing and fixing bugs, decompiling the entire game 1:1, fixing the avalanche of bugs in the original, adding new
and hopefully useful features for players and level designers, writing the docs, making icons, models and SDK example
maps, and much more. I'm one person doing a monumental amount of work, so if something doesn't work right, please let
me know, politely.
