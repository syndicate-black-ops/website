# Install Syndicate Black Ops 2.0.0

## You need

- Half-Life 25th Anniversary (the current Steam version)

## Before you install

1. If you have the old version from 2004 (Syndicate 1.38), rename your existing `syndicate` folder to `syndicate_138`
2. If you still have the playtest version from October 17, 2026, delete it. The first public release is a fresh install
3. If you have a `syndicate_downloads` folder from 1.38, it will still work with 2.0.0, no need to delete it

## Install

Download [sbo-v2.0.0.zip](https://github.com/syndicate-black-ops/syndicate-black-ops/releases/latest/download/sbo-v2.0.0.zip)

**Windows**

1. Open `C:\Program Files (x86)\Steam\steamapps\common\Half-Life`
2. Copy the `syndicate` and `syndicate_addon` folders from the zip into it
3. Restart Steam and start Syndicate Black Ops from your library

**Linux**

1. Open `~/.local/share/Steam/steamapps/common/Half-Life`
2. Copy the `syndicate` and `syndicate_addon` folders from the zip into it
3. Restart Steam and start Syndicate Black Ops from your library

## Custom content

Put any custom content in `syndicate_addon`. In the game menu, go to Options > Content and make sure "Allow custom addon content" is turned on
